# belma3qoul-web

تطبيق ويب مستقل لـ **بزار كل شيء بالمعقول**، مبني ليجمع الموقع العام، صفحة المفاجأة، ولوحة التحكم والـAPI في مشروع واحد.

## البنية

- `/` — الصفحة التعريفية والروابط العامة.
- `/surprise` — صفحة المفاجأة.
- `/admin` — تسجيل الدخول ولوحة التحكم.
- `/admin/sales` و`/admin/products` و`/admin/inventory` ... — وحدات الإدارة.
- `/api/health` — فحص صحة السيرفر.
- `/api/auth/login` و`/api/auth/logout` و`/api/auth/me` — المصادقة.
- `/api/settings` — إعدادات الموقع.
- `/api/stats` — الإحصائيات.
- `/api/links` — روابط التواصل.

## التشغيل

```bash
npm install
npm run build
npm start
```

للتطوير:

```bash
npm run dev
```

## إعداد كلمة المرور

افتراضيًا كلمة المرور المحلية هي `admin123` للتطوير فقط. في الإنتاج اضبط المتغير:

```bash
ADMIN_PASSWORD=كلمة_مرور_قوية
```

بيانات الموقع تحفظ في `data/site.json`، والسيرفر يعيد `index.html` للمسارات التطبيقية حتى يعمل التنقل المباشر والتحديث على `/surprise` و`/admin/*`.
