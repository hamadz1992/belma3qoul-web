# belma3qoul-web

موقع **بزار كل شيء بالمعقول** مع صفحة تعريفية واحدة ونظام مفاجأة/جوائز قابل للإدارة.

## المكونات

- `/` — الصفحة التعريفية الواحدة.
- `/surprise` — صفحة المفاجأة التي يصل إليها الزائر عبر QR.
- `/admin` — لوحة التحكم.
- `/api/qr` — QR ديناميكي يشير إلى صفحة المفاجأة.
- `/api/promotion/public` — الحالة العامة للحملة بدون كشف مخزون الجوائز.
- `/api/promotion/play` — تنفيذ محاولة السحب من السيرفر.
- `/api/admin/promotion` — إدارة إعدادات الحملة.
- `/api/admin/prizes` — إدارة الجوائز والكميات والأوزان والروابط.
- `/api/admin/plays` — إدارة المشاركات والفائزين وحالة الاستلام.

## أنواع الجوائز

يمكن للإدارة إنشاء:
- قسيمة شراء.
- جائزة عينية.
- رابط Facebook أو أي رابط خارجي.
- رسالة مثل «حظ أوفر».

لكل جائزة عدد إجمالي وكمية متبقية ووزن في السحب، ويقوم السيرفر بإنقاص الكمية عند الفوز.

## التشغيل المحلي

```bash
npm install
npm run dev
```

للإنتاج:

```bash
npm install
npm run build
npm start
```

## إعداد كلمة مرور الإدارة

في بيئة الإنتاج يجب ضبط:

```bash
ADMIN_PASSWORD=ضع_كلمة_مرور_قوية_هنا
NODE_ENV=production
```

إذا لم يتم ضبط `ADMIN_PASSWORD` في الإنتاج، سيرفض السيرفر تسجيل دخول الإدارة. قيمة `admin123` متاحة فقط افتراضيًا أثناء التطوير المحلي.

## البيانات والاستضافة

يتم حفظ إعدادات الموقع في `data/site.json` وإعدادات الحملة والجوائز والمشاركات في `data/promotions.json`.

يجب أن توفر الاستضافة **Persistent Disk/Volume** إذا أردت الاحتفاظ بالمشاركات والجوائز بعد إعادة تشغيل الخدمة. إذا كانت الاستضافة مؤقتة، استخدم قاعدة بيانات دائمة قبل تشغيل حملات حقيقية.

## الأمان

- نتيجة السحب تُحدد على السيرفر، وليس في متصفح الزائر.
- الـQR لا يحتوي على الجائزة نفسها، بل يفتح `/surprise`.
- توجد حماية من محاولات تسجيل الدخول الكثيرة وطلبات السحب المتكررة.
- جلسة الإدارة تستخدم Cookie من نوع HttpOnly وSameSite، وتصبح Secure تلقائيًا في الإنتاج.
- استجابات API تستخدم رؤوس حماية أساسية مثل `nosniff` و`SAMEORIGIN`.
- لا يتم كشف قائمة الجوائز أو كمياتها عبر endpoint العام.

## التحقق المستمر

يوجد GitHub Actions workflow يقوم بتثبيت dependencies وتشغيل `npm run build` عند كل push إلى `main` وعند Pull Requests، لضمان عدم إدخال كود لا يبني بنجاح.
