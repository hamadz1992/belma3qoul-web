# Belma3qoul

الموقع الرسمي لمحل **كل شيء بالمعقول** — صفحة واحدة خفيفة وسريعة تعرض الهوية، روابط التواصل، المنشورات المميزة، آخر المنشورات، الموقع، وQR Code.

## التقنية

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- React Router

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الهيكل

- `src/components` للمكوّنات القابلة لإعادة الاستخدام
- `src/layouts` للتخطيطات
- `src/pages` للصفحة الرئيسية
- `src/router` للتنقل
- `src/constants` لبيانات الموقع والروابط
- `src/styles` للأنماط المساعدة

## النشر

المشروع جاهز للرفع على GitHub والنشر على Render.
