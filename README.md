# belma3qoul-web

موقع **بزار كل شيء بالمعقول** مع صفحة تعريفية واحدة ونظام مفاجأة/جوائز قابل للإدارة.

## المكونات

- `/` — الصفحة التعريفية الواحدة.
- `/surprise` — صفحة المفاجأة التي يصل إليها الزائر عبر QR.
- `/admin` — لوحة التحكم.
- `/api/qr` — QR ديناميكي يشير إلى صفحة المفاجأة.
- `/api/promotion/play` — تنفيذ محاولة السحب من السيرفر.
- `/api/admin/promotion` — إدارة إعدادات الحملة.
- `/api/admin/prizes` — إدارة الجوائز والكميات والأوزان والروابط.
- `/api/admin/plays` — إدارة المشاركات والفائزين وحالة الاستلام.

## أنواع الجوائز

يمكن للإدارة إنشاء:
- قسيمة شراء.
- جائزة عينية.
- رابط Facebook أو أي رابط خارجي.
- رسالة مثل «حظ أوفر».

لكل جائزة عدد إجمالي وكمية متبقية ووزن في السحب، ويقوم السيرفر بإنقاص الكمية عند الفوز.

## تشغيل محلي

```bash
npm install
npm run dev
```

للإنتاج:

```bash
npm install
npm run build
npm start
```

## كلمة مرور الإدارة

اضبط المتغير:

```bash
ADMIN_PASSWORD=غيّر_هذه_القيمة
```

إذا لم يتم ضبطه، يستخدم السيرفر `admin123` كقيمة افتراضية للتطوير فقط. **يجب تغييره قبل النشر العام.**

## البيانات

يتم حفظ إعدادات الموقع في `data/site.json` وإعدادات الحملة والجوائز والمشاركات في `data/promotions.json`. في الاستضافة يجب استخدام تخزين دائم للملفات حتى لا تضيع المشاركات عند إعادة تشغيل الخدمة.

## ملاحظة أمنية

نتيجة السحب تُحدد على السيرفر، وليس في متصفح الزائر. الـQR لا يحتوي على الجائزة نفسها، بل يفتح `/surprise`، ولذلك يمكن تغيير الحملة والجوائز دون إعادة طباعة QR.
